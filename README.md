hx-libs is a Cargo workspace holding the Hotline protocol pieces that don't belong to any one program: hxproto, the wire format (including the tracker protocol, for servers and clients alike); hxfiles-xfer, the file-transfer codec; and hxhfs, the HFS metadata and resource-fork sidecars. hxcrypto will move here from GtkHx when hxd-ng implements HOPE. GtkHx and hxd-ng pull these in as git dependencies. hxproto and hxfiles-xfer also build for wasm32-unknown-unknown, for a browser client; hxproto's emoji shortcode tables sit behind its default `emoji` feature, so a build that doesn't need them can leave them out.
