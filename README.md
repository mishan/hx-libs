hx-libs is a Cargo workspace holding the Hotline protocol pieces that don't belong to any one program: hxproto, the wire format (including the tracker protocol, for servers and clients alike); hxfiles-xfer, the file-transfer codec; hxhfs, the HFS metadata and resource-fork sidecars; and hxsession, a client session over the classic control connection — handshake, login, agreement, replies matched to requests, the keep-alive, and the server's pushes as events — that does no I/O of its own, so the same session runs over a TCP socket, a WebSocket to a relay, or a test's script. hxcrypto will move here from GtkHx when hxd-ng implements HOPE. GtkHx and hxd-ng pull these in as git dependencies. hxproto, hxfiles-xfer and hxsession also build for wasm32-unknown-unknown, for a browser client; hxproto's emoji shortcode tables sit behind its default `emoji` feature, so a build that doesn't need them can leave them out.
